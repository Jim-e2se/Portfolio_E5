03

Réalisations professionnelles

Trois situations vécues chez Savencia, présentées selon le même déroulé : contexte, actions, résultat.

Incident majeur

Panne du VPN Zscaler

B1.2

Contexte
Une panne de Zscaler, la solution VPN de l'entreprise, empêche les utilisateurs de travailler. Le support reçoit plus de 160 appels en moins de trois heures.
Actions
Prise en main à distance impossible, la connexion étant justement coupée. Guidage de chaque utilisateur au téléphone, pas à pas, avec clarté et rapidité malgré l'enchaînement des appels.
Résultat
La même action a rétabli l'accès pour tous : renouveler la configuration réseau du poste avec ipconfig /release puis ipconfig /renew.

Projet

Arbre de décision du support sur Elium

B1.4 · B1.5

Contexte
Les procédures du support étaient réparties entre plusieurs équipes, ce qui compliquait le traitement des demandes et la formation des nouveaux arrivants.
Actions
Conception dans Elium d'un arbre de décision : à partir du symptôme décrit par l'utilisateur, il guide le technicien jusqu'à la solution, ou jusqu'à l'équipe à qui transmettre la demande. Conduite en mode projet : expression du besoin, cahier des charges, planification (PERT, Gantt, suivi dans Asana), plan de test et recette.
Résultat
Une base commune au Support Utilisateur, qui sert aussi de support de formation.

Communication

Mails d'information et tutoriels Viva Engage

B1.3 · B1.5

Contexte
Les utilisateurs des sociétés du groupe, pour la plupart non techniques, doivent être prévenus des interventions et savoir régler seuls les demandes courantes.
Actions
Rédaction de mails d'information, par exemple avant une migration de serveur. Publication de tutoriels dans l'espace IT Self-Help de Viva Engage, le réseau social interne du groupe.
Résultat
Des utilisateurs prévenus à l'avance, et des réponses disponibles sans passer par le support.

Projets de l'épreuve E6

Projet E6 · Bastion d'administration

Bastion PAM avec Apache Guacamole

Équivalent open source d'une solution PAM comme CyberArk, hébergé sur un second serveur Proxmox (pve2). Apache Guacamole devient le point d'accès unique pour administrer les serveurs en SSH et en RDP. Le labo comprend un domaine Active Directory (guacamol.internal, contrôleur DC-01 sous Windows Server) et un serveur de fichiers avec des partages par groupe AD. Un pare-feu OPNsense isole le labo du réseau domestique ; le jury y accède à distance par Tailscale.

  • Apache Guacamole
  • Proxmox VE
  • Windows Server
  • Active Directory
  • OPNsense
  • Tailscale

Projet E6 · Messagerie inter-entreprises

Chat entre deux entreprises avec Matrix

Messagerie privée entre deux entreprises fictives, Arkotech et Atome, sans aucun service exposé sur Internet. Chaque entreprise dispose de son serveur Matrix (Synapse) et de son pare-feu OPNsense ; les deux sites sont reliés par un VPN IPsec site à site. Les conversations privées sont chiffrées de bout en bout dans le client Element. Active Directory est déployé dans le LAN d'Arkotech. Le projet est hébergé sur le Proxmox de l'école.

  • Matrix Synapse
  • Element
  • OPNsense
  • VPN IPsec
  • Nginx Proxy Manager
  • Active Directory

Projet personnel

Homelab

Jimhub

Un serveur Proxmox VE qui héberge une VM NAS (OpenMediaVault) et des conteneurs LXC pour les services : Nextcloud, Vaultwarden, Jellyfin. L'accès depuis l'extérieur passe uniquement par un VPN WireGuard ; AdGuard Home filtre le DNS et Caddy publie les services en HTTPS avec un certificat wildcard. Zabbix supervise l'ensemble depuis un second serveur.

  • Proxmox VE
  • OpenMediaVault
  • WireGuard
  • AdGuard Home

Projet professionnel

Objectif après le BTS : poursuite d'études en cybersécurité, pour devenir pentester.

Le métier de pentester

Le pentester, ou testeur d'intrusion, est mandaté par une organisation pour attaquer ses systèmes de façon autorisée et encadrée. Il cherche les failles avant qu'un attaquant ne les exploite, mesure leur impact, puis les documente et propose des corrections.

Compétences attendues

  • Réseaux et protocoles (TCP/IP, routage, filtrage, VPN)
  • Systèmes Windows et Active Directory, Linux
  • Sécurité des applications web
  • Méthodologie d'audit : reconnaissance, exploitation, élévation de privilèges
  • Rédaction de rapports et restitution au client
  • Respect du cadre légal et éthique
